
# Хакатон: Graph-RAG для курса Graph Neural Networks

## Описание

В этом хакатоне участникам предлагается разработать систему **Retrieval-Augmented Generation (RAG)** для автоматического ответа на вопросы по курсу **Graph Neural Networks (GNN)**.

Ключевая особенность хакатона — **использование графов и графовых нейросетей (GNN)** для улучшения этапа retrieval в RAG-системе.

Участникам предоставляется готовый **baseline RAG без GNN**, который необходимо расширить и улучшить за счёт графовых методов.



## Цель

Построить RAG-систему, которая:
1. принимает вопрос на естественном языке;
2. извлекает релевантные фрагменты учебных материалов;
3. формирует контекст;
4. генерирует корректный и краткий ответ с помощью LLM;

и **превосходит baseline** за счёт использования:
- графовых представлений,
- GNN,
- многошагового (multi-hop) retrieval.

## Что требуется реализовать

Необходимо модифицировать или расширить baseline так, чтобы этап retrieval был улучшен с помощью **графов и GNN**.

Допускается:
- расширять pipeline RAG
- построение графов между чанками (chunk → chunk);
- построение графов «концепт → чанк» или «термин → чанк»;
- использование графовых эмбеддингов;
- reranking retrieved chunks с помощью GNN;
- multi-hop retrieval;
- использование GNN:
  - GCN
  - GraphSAGE
  - GAT
  - HGT
  - другие обоснованные архитектуры.

## Оценивание

Основной критерий — **качество ответов на вопросы** + архитектура RAG

В оценке могут использоваться:
- семантическое сходство с эталонными ответами по метрике BertScore
- ручная проверка лучших решений

Дополнительно учитывается:
- корректность и обоснованность использования графов
- качество архитектурного решения
- воспроизводимость кода
- ясность и полнота описания подхода
